# Confirmation & Clarification Rule

1. **Always Confirm Major Changes**:
   - Before performing major code overhauls, deleting files, regenerating primary media/assets, or executing destructive actions, always explicitly confirm with the user first.
2. **Ask If Confused**:
   - If requirements, design intent, or user instructions are ambiguous or underspecified, stop and ask the user for clarification rather than making assumptions.

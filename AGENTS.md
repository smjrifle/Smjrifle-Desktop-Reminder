# UI & UX Design Guidelines & Reference Kit

When designing and building user interfaces (desktop, web, or mobile apps), always draw inspiration and design patterns from the following modern UI kits and design systems:

- **[beautifului.dev](https://beautifului.dev)**: Rich aesthetics, vibrant subtle accents, card elevation, clean glassmorphism, and modern visual hierarchy.
- **[beui.dev](https://beui.dev)**: Sleek, high-craft UI components with refined padding, border radii, and dark/light mode balance.
- **[rareui.com](http://rareui.com)**: Premium micro-interactions, dynamic hover/focus states, bespoke widget styling, and tactile feel.
- **[transitions.dev](https://transitions.dev)**: Fluid animation curves, smooth entry/exit transitions, and natural easing for notifications/modals.
- **[ui.shadcn.com](http://ui.shadcn.com)**: Clean typography, accessible contrast, structured component ergonomics, pill badges, and refined neutral palettes.

### Core Principles to Apply:
1. **Typography & Hierarchy**: Modern system typography (SF Pro on macOS, Segoe UI on Windows, Inter on Linux) with distinct weights, balanced line heights, and crisp hierarchy.
2. **Surface & Depth**: Subtle borders (`rgba(255, 255, 255, 0.08)` to `0.15`), layered dark glassmorphism/acrylic backgrounds (`rgba(24, 24, 27, 0.88)`), and soft drop shadows.
3. **Tactile Micro-interactions**: Smooth hover transitions, active button press feedback, pill tags, icon-rich buttons, and polished states.
4. **Fluid Motion**: Smooth fade-ins and slide transitions for toasts, dialogs, and dynamic lists.

## 🧠 Memory & Workflow Rules

1. **Always Confirm Major Changes**:
   - Before deleting files, rewriting entire components, discarding working features, reverting user work, or generating drastic new visual assets, always explicitly ask the user for confirmation first.
2. **Ask If Confused**:
   - If user instructions or intent are ambiguous, underspecified, or unclear, stop and ask clarifying questions instead of making assumptions or taking unilateral actions.
